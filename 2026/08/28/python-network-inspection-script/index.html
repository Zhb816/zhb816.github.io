用 Python 写了个简单的设备巡检脚本

手上有几十台网络设备，每天手动登录看状态太麻烦了，写了个简单的 Python 脚本批量巡检，分享一下思路。

用什么库

用的是 Netmiko，它是 Paramiko 的封装，专门针对网络设备做了优化，支持华为、华三、思科等主流厂商。

后续优化

这个脚本只是最基础的版本，后面可以加：

  1. 多线程：几十台设备串行跑太慢，用 concurrent.futures 并发
  2. 结果入库：把每次巡检结果存到 SQLite，方便看趋势
  3. 告警通知：异常设备自动发飞书消息或者邮件
  4. 配置备份：巡检同时把 running-config 备份下来

网络运维自动化这块水挺深的，Netmiko 只是入门，后面可以看看 NAPALM、Nornir 这些框架。不过对日常巡检来说，Netmiko 够用了。
